Tempo/Density/Pitch

These are the sample audios provided to participants to help them understand musical parameters (tempo, pitch, and density) prior to answering the Formative Study questionnaires (Section 3). These audio samples have been created by tweaking the same melody of Mozart’s K.265 (Ah! Vous Dirai-je, Maman) in 3 different parameters using 3 variations (low, normal, high). Participants were able to listen to these audio samples whenever they need to during the survey.
